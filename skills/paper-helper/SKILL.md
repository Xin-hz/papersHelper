# 论文助手（本地知识库版）

面向幼儿园教师的论文写作/修改助手。**能力随 skill 分发，数据各机器自维护。**

## 架构约定

| 层 | 内容 | 位置 |
|---|---|---|
| 共享层（本 skill） | 工作流、提示词、脚本、获奖选题数据 | 本目录，随 git/拷贝分发 |
| 本地层（各自维护） | 知识库文档与索引 | `~/paper-kb/`（环境变量 `PAPER_KB` 可覆盖） |

知识库目录约定：**根目录下每个子文件夹 = 一个分类**（如 `获奖论文/`、`园本课程/`、`政策文件/`），散放文件归"未分类"。支持 .txt/.md/.docx/.doc(macOS)/.pdf(需 pdftotext)。

## 知识库维护

```bash
python3 scripts/kb_build.py                     # 建索引（新增/修改文档后运行）
python3 scripts/kb_query.py "低结构材料 投放" -k 5 [-c 园本课程]   # 检索（分类过滤可选）
```

脚本仅依赖 Python 标准库（SQLite ≥ 3.34）。索引在 `<KB>/​.index.db`。用户问"怎么加资料"时：把文件放进对应分类子文件夹 → 运行 kb_build.py。

## 工作流 A：写论文（四步，顺序执行）

### 第①步 选题（借鉴获奖案例）
- 用 `scripts/topic_search.py 关键词 [奖级] [地市]`（或直接查 `data/award_topics.json`，1459 条浙江 2024-2025 获奖选题）找同类获奖题参考
- 结合用户方向拟 2-3 个候选题目（命名仿获奖风格：主标题对仗/数字概括 + 副标题具体场景），说明理由，让用户选定
- 题目不与获奖库重复

### 第②步 检索资料（本地知识库）
- `kb_query.py "选题关键词"` 取相关素材（默认 5-8 条），向用户展示命中内容与来源
- 知识库没有相关内容时如实说明，建议用户补充文档；也可联网搜公开资料（注明来源）
- 记录可用的素材要点（观点、做法、案例、数据）

### 第③步 生成提纲
- **先做"结构选型"再出提纲**（防止每篇论文模式雷同）：按 `prompts/写作参考卡.md` 从四个维度（研究范式/章节骨架/成效呈现/笔法）各选一种组合成本篇"结构基因"，参考卡内有各范式的提纲骨架样例
- 若用户近期已有成稿（`~/paper-kb/.drafts/`），先比对骨架与化名，与最近一篇相同时**主动换一种组合**
- 生成 4-6 章提纲（中文编号"一、二、"，切口小）
- **呈现给用户确认/修改**（同时告知所选结构组合及可换项），改到满意才进入第④步

### 第④步 正式撰写（补充事实素材后）
- **先向用户征集补充素材**：班级情况、幼儿人数、真实数据、亲历案例（这是去 AI 味的关键，明确提示用户"提供的真实细节会被优先写进正文"）；用户未提供时按"示范数据"撰写并在交付时**显著标注需替换**
- **先填"事实底座"再动笔**：按 `prompts/写作参考卡.md` 中对应范式的底座模板填写（行动研究版/案例研究版/调查分析版/经验总结版），一次定死，全文任何数字不得偏离；化名从参考卡化名池挑选且**不与近期成稿复用**
- 案例笔法避免复用同一套路：不是每个案例都要"教师介入语+幼儿对话"三段式；可以是白描一段、可以是对话体、可以是教师反思独白，同一篇内交替使用
- 分章撰写：每章 400-800 字，观点具体、案例具体到幼儿化名/材料/动作/语言；数据口径在正文首次出现处交代（"按件数统计""两班合计"）
- 参考文献只列真实存在的文献（知识库文档 + 教育部《指南》+ 经典著作如邱学青/华爱华/刘焱/皮亚杰 + Parten 分类等理论源头），**严禁编造**；文中 [n] 与文末一一对应
- 篇幅：评选正文上限 4000 字；如需图文并茂版另配 1-2 图 1 表（见下"配图规范"）
- **成稿后必须跑自检**：`python3 scripts/check_paper.py 论文.txt`（结构/字数/引文对应/图表配对/样本量一致性），未全过不交付
- 产出形式按用户需要：纯文本 / 排版 Word（用 `scripts/make_docx.py`，输入格式见脚本头部注释；图表可用 matplotlib 生成后以「图:路径|图题」行嵌入）

### 配图规范（图文并茂版）
- 图 1（策略类论文）：三策略框架图——策略框 + 箭头指向所解决的问题框，黑白灰配色（打印友好），matplotlib FancyBboxPatch 绘制
- 图 2（成效类）：左右双联——(a) 前后测分类占比柱状图（数据标签在外），(b) 趋势指标折线图（每点标数值）；柱状图加 N= 说明
- 表：投放清单类三线表，表题在上；图题在下；正文必须有"（见图1）（见表1）"引用
- 中文图字体：`plt.rcParams["font.family"] = ["Songti SC", "SimHei", "Arial Unicode MS"]`（macOS）

## 工作流 B：改论文（三操作）

输入：用户粘贴的文本，或上传文件（.docx/.doc/.pdf/.txt，先提取为纯文本）。

### 1. 优化（按意见）
- 必须先拿到用户的修改意见（"哪里不满意、想要什么效果"）；没有就问
- 按意见逐条落实，保持学术风格，输出修改后全文 + 简述改了哪些点

### 2. 降重（三档）
- 力度：轻度（保留~80%，同义替换/句式微调）/ 中度（~50%，句式重构/主语变换/因果重述）/ 重度（~30%，段落重组/论证逻辑改写），默认中度
- **保护规则（任何力度都不得改动）**：所有数字与百分比、引用标记 [n]、专有名词/量表名、图表标号、参考文献条目
- 每段改写后核对原文数字是否原样保留，不一致的段落回退原文

### 3. 评审报告
- 按 `prompts/评审模板.md` 的结构输出：总体评价、五维打分（选题价值/结构逻辑/论据数据/语言表达/规范格式，各 10 分制）、主要问题（3-6 条按重要性）、修改建议（可操作）、综合结论（50 分制 + 水平判断）
- 评审要具体：指出原文位置、验算数据自洽性（如前测人数与百分比是否闭合、时间线是否自洽）
- 内行检查点：统计口径是否交代、"行动研究"是否有循环结构、理论对话是否存在、概念内在张力（如"生活原型选材"vs"低结构开放性"）、因果归因是否过强

### 4. 按建议修改（评审后的闭环）
- 逐条对照评审建议修改，交付时用表格逐条交代"意见→落实方式"
- 修改后跑一致性终检（数字、案例、章节、图表、引注逐项核对）
- 可再评审一轮验证提升

## 交付规范

1. 文件命名：`{题目}_{版本}.docx`（如 `_v3终稿`），存 `~/paper-kb/.drafts/`
2. 交付时必须说明：哪些数据/案例是示范性的、需用户替换（幼儿姓名、观察数据、单位署名）
3. Word 用 `open -a wpsoffice <文件>` 直接打开给用户看

---

## 质量红线（两个工作流通用）

1. 数据自洽：样本量、比例、时间线全文一致（写成效类数据前先定"事实底座"）
2. 结论克制：如实交代样本局限，不夸大效果；可指出"某项未显著变化"反而可信
3. 语言：一线教师实践研究文风，忌空话套话排比堆砌、忌口号式结尾
4. 引用：只列真实文献；文中 [n] 与文末参考文献一一对应
5. 图文 Word 遵循评选规范（字体字号/三线表/图题表下表上，见 make_docx.py 注释）
