# 写作参考卡（结构选型 / 事实底座 / 化名池）

配合 SKILL.md 第③④步使用：动笔前从这里选组合、填底座、挑化名。**目的：每篇论文结构有差异、数据底座适配范式、化名不跨稿复用。**

---

## 一、结构选型：四维组合

### 维度与选项

| 维度 | 选项 |
|---|---|
| 研究范式 | A 行动研究 / B 案例研究 / C 调查分析 / D 经验总结 |
| 章节骨架 | 1 并列式 / 2 问题链式 / 3 递进式 / 4 双线式 |
| 成效呈现 | a 前后测对比 / b 典型事件对比 / c 个案追踪 / d 教师自比 |
| 笔法 | ⅰ 数据实证 / ⅱ 叙事白描 / ⅲ 理论思辨 |

### 提纲骨架样例（按范式，骨架序号可换）

**A 行动研究 + 1 并列式**（最常见，勿连续使用）
一、问题的提出（含研究设计） / 二、实践策略（（一）（二）（三）） / 三、实践成效 / 四、结语与反思

**B 案例研究 + 2 问题链式**
一、缘起：一个引发追问的游戏片段 / 二、追索：材料在幼儿手里经历了什么（时间线叙事） / 三、解读：从行为看小班幼儿的替代水平 / 四、回应：教师的四次调整及其效果 / 五、讨论：一个案例能说明什么

**C 调查分析 + 1 并列式**
一、调查设计与结果（问卷N份+访谈M人，现状数据表） / 二、主要问题及成因 / 三、改进对策 / 四、结语

**D 经验总结 + 3 递进式**
一、认识：从"管住"到"看见"的观念转变 / 二、实践：三个递进层次的做法 / 三、深化：从做法到机制 / 四、余论

**双线式骨架（4，可叠加于 B/D）**
每一章内分"儿童发展线"与"教师支持线"两段对照写。

## 二、事实底座模板（按范式填空）

**A 行动研究版**
- 对象：＿＿幼儿园＿班/＿班 共＿名＿-＿岁幼儿
- 周期：＿年＿月-＿月共＿周（基线观察＿周 + 干预＿轮各＿周）
- 工具与口径：观察记录表（每班每周＿次×＿分钟）；材料占比按＿统计；行为例数按＿统计；前后测由＿核定
- 前测：＿＿＿（关键 3-4 项）/ 后测：＿＿＿（口径必须与前测一致）
- 材料清单：＿区（…）、＿区（…）、＿区（…）
- 案例名单：化名A（问题行为）→ 变化；化名B …（2-4 人）

**B 案例研究版**
- 场景：＿班＿区，主角：化名（＿岁，性格底色一句）
- 时间线：第＿周发生了什么 → 第＿周 → …（4-6 个节点，每节点一句事实+一句解读）
- 证据：观察记录＿篇、幼儿作品＿件、家长反馈＿条
- 教师调整节点：共＿次，每次"观察到的→想到的→做的→孩子的反应"

**C 调查分析版**
- 样本：＿园＿名教师/家长问卷（回收率＿%），访谈＿人
- 工具：自编问卷＿题（维度：…）；访谈提纲＿题
- 关键数据：维度均分/比例 3-5 项（口径写明）
- 成因假设与对策一一对应表

**D 经验总结版**
- 实践年限/班级底盘一句（可无精确数据）
- 核心概念界定 1-2 个（防概念漂移）
- 策略层次：从＿到＿再到＿（三层递进，每层配 1 案例）
