# 幼儿园教师 AI 论文助手 - 前端页面流程

## 一、整体流程

```
┌─────────────────────────────────────────────────────────────────┐
│  首页（工作台）                                                    │
│  功能入口：论文 / 教案 / 教学案例 / 知识库                          │
└───────────────┬─────────────────────────────────────────────────┘
                │
    ┌───────────┼───────────┬───────────────┐
    ▼           ▼           ▼               ▼
┌────────┐  ┌────────┐  ┌────────────┐  ┌────────────┐
│ 论文   │  │ 教案   │  │ 教学案例   │  │ 知识库     │
│ 生成   │  │ 生成   │  │ 生成       │  │ 上传+问答  │
│ 润色   │  │        │  │            │  │            │
│ 扩写   │  │        │  │            │  │            │
│ 降重   │  │        │  │            │  │            │
└────────┘  └────────┘  └────────────┘  └────────────┘
```

## 二、路由与页面

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 工作台，6 大功能卡片入口 |
| `/paper` | 论文 | 子 Tab：生成 / 润色 / 扩写 / 降重 |
| `/lesson` | 教案 | 教案生成表单 + 结果 |
| `/case` | 教学案例 | 教学案例生成表单 + 结果 |
| `/knowledge` | 知识库 | 上传文件 + 问答输入 + 回答与来源 |

## 三、页面交互流程

### 1. 首页
- 展示应用名称与简介
- 6 个功能卡片：论文生成、教案生成、教学案例生成、论文润色、论文降重、知识库问答
- 点击跳转对应页面

### 2. 论文页 `/paper`
- 顶部 Tab：生成 | 润色 | 扩写 | 降重
- **生成**：标题、大纲（可选）、是否用知识库 → 提交 → 展示生成正文
- **润色**：文本框粘贴待润色内容、侧重点（可选）→ 提交 → 展示润色结果
- **扩写**：文本框、指定扩写部分（可选）、是否用知识库 → 提交 → 展示扩写结果
- **降重**：文本框、侧重点（可选）→ 提交 → 展示降重结果

### 3. 教案页 `/lesson`
- 表单：教学主题（必填）、年龄段、领域、课时、是否用知识库
- 提交 → Loading → 展示生成的教案正文

### 4. 教学案例页 `/case`
- 表单：案例主题（必填）、场景说明、是否用知识库
- 提交 → Loading → 展示生成的教学案例正文

### 5. 知识库页 `/knowledge`
- **上传区**：选择 PDF/DOCX 文件，上传 → 显示“已上传，共 N 个片段”
- **问答区**：输入问题、可选检索条数 → 提交 → 展示回答 + 引用来源列表

## 四、通用交互

- 所有“生成/润色/扩写/降重/问答”请求：按钮提交 → 请求中禁用按钮 + Loading → 成功展示结果区，失败 Toast/文案提示
- 结果区支持一键复制
- 顶部导航高亮当前页，移动端可折叠为汉堡菜单（可选）

## 五、技术选型（前端）

- **框架**：Vue 3 + Vite
- **路由**：Vue Router
- **请求**：fetch，baseURL 可配置（如 `/api` 或完整后端地址）
- **样式**：CSS 变量 + 简单布局，无 UI 库依赖，便于部署

## 六、部署

- 开发：`npm run dev`，通过 Vite 代理或后端 CORS 访问 API
- 构建：`npm run build` → `dist/` 静态资源
- 部署方式一：将 `dist/` 挂到 FastAPI 的 StaticFiles
- 部署方式二：将 `dist/` 部署到 Nginx / 对象存储等静态托管
